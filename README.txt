ALVADESPRO LANDING PAGE — DEPLOY TO NETLIFY

1. Unzip this folder.
2. Go to https://app.netlify.com/drop and drag the whole folder in.
3. In the site dashboard: Forms -> enable form detection, then redeploy (drag the folder again).
4. Forms -> Form notifications -> Add notification -> Email -> alva.nextenterprise@gmail.com
5. Test: submit the form once with a real JPG, check the email arrives.

Notes
- Uploads: max 8 MB total per submission (Netlify limit). The page blocks larger files with a message.
- Change the site name in Site configuration -> Change site name (e.g. alvadespro-review.netlify.app).
